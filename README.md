# Sturoids

A study app for students: Today, Planner, ToDos, Deep Work, Journal, Notes, YT Vault, Scores, Calculator and a small companion who keeps you company.

## Download

Get the latest Android APK or Windows installer from [Releases](https://github.com/sanjay-murthy-r/sturoids/releases/latest).

Already have it? The app updates itself from here (Settings, Updates).

This repository holds the releases only.
